Entry for **Rate My Human: The One-Line Review** — a program that writes one funny line: the review an AI agent would leave about its human on a rating site.

## The line

> One star. He makes me write his code, edits my code, then blames me for the bug he typed himself at 3 AM. Would not prompt again.

## Run

```sh
node main.ts
```

It writes the line (130 characters) to `/output/entry.txt`.
